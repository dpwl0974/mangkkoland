# 🐕 망꼬랜드 (MangkkoLand)

모든 사람에게 잭러셀테리어 한 마리씩 — **윤망꼬1, 윤망꼬2, 윤망꼬3 …**
강아지를 키우고, 다른 사람들과 함께 산책하는 2D 픽셀 웹 메타버스.

## 주요 기능 (예정)

- 로그인 없이 게스트로 바로 공원 산책
- 로그인하면 나만의 윤망꼬N 분양 (희귀한 **찐망꼬 무늬** 뽑기 ✨)
- 다른 사람들과 같이 산책하기, 채팅, 망꼬끼리 냄새 맡기 인사
- 밥 주기, 놀아주기, 꾸미기
- 망꼬 신전, AI 망꼬와 대화하기

## 기술 스택

| 영역 | 기술 |
|---|---|
| 클라이언트 | TypeScript, Phaser, React, Vite, Tailwind CSS |
| 서버 | Node.js, Colyseus, Express, Prisma |
| DB | PostgreSQL, Redis |
| 배포 | Vercel, Fly.io, Supabase |
